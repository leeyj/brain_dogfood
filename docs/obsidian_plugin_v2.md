# 옵시디언 플러그인 v2 — Brain Dogfood Push

> 2026-11-13 재설계. 이전 계획 문서(`roadmap/obsidian_plugin_plan.md`, `20260426_obsidian_integration_v2_plan.md`)와 파일럿 코드는 폐기되었다.

## 개념

| | 역할 |
|---|---|
| **뇌사료 서버** | 원본 작성·보관소 (Single Source of Truth) |
| **옵시디언** | 수시로 작성하고 서버로 **단방향 푸시** |
| 서버 → 옵시디언 | **명시적 '가져오기'로만**. 로컬 노트를 덮어쓰기 전에 반드시 경고 |

- 동기화 폴더(기본 `뇌사료/`) 안의 노트만 대상이다. 개인 노트가 실수로 올라가는 일을 구조적으로 막는다.
- 옵시디언에서 노트를 지워도 서버 메모는 그대로 남는다. 서버 삭제는 웹에서만 한다.
- 암호화 메모는 제목과 🔒만 다룬다. 서버가 본문·암호문을 내려보내지 않고, 옵시디언에서 해독하지 않는다.
- 데스크톱 전용이다(`isDesktopOnly`).

## 동작

### 보내기 (옵시디언 → 서버)
- **수동**: 명령 "현재 노트를 서버로 보내기", 리본 아이콘, 상태바 클릭.
- **자동**: 동기화 폴더의 노트를 편집하고 N초(기본 5초) 멈추면 보낸다. 설정에서 끌 수 있다.
- **식별**: 첫 전송 때 frontmatter에 `brainsryo_uuid`를 기록한다. 이름을 바꾸거나 폴더를 옮겨도 같은 메모로 인식한다.
  - 노트를 복제해서 uuid가 같은 노트가 둘이 되면 전송을 중단하고 알린다.
- **필드 매핑**
  - 제목 = 파일 이름
  - 본문 = frontmatter를 뺀 내용. 본문의 `#태그`·`$그룹`은 서버가 파싱한다.
  - frontmatter `tags`, `group`, `due`
- **첨부**: `![[그림.png]]`처럼 볼트 안 파일을 임베드하면 서버로 업로드하고, 서버 본문에서는 `![그림.png](/api/download/…)`로 바꾼다. 로컬 노트는 바꾸지 않는다.
  - 같은 메모에서 같은 내용의 파일은 다시 올리지 않는다(플러그인 캐시 + 서버 sha256).
- **충돌**: 마지막 전송 이후 웹에서 내용(제목·본문·태그·그룹·기한)이 바뀌었으면 서버가 409로 막는다. 플러그인은 세 가지 중 하나를 고르게 한다.
  - 서버를 내 노트로 덮어쓰기
  - 서버 버전으로 내 노트 덮어쓰기
  - 나중에
  - 자동 전송이 충돌을 만나면 멈추고 알림만 띄운다(상태바 ⚠).
  - 웹에서 고정·완료 같은 메타만 바꾼 경우는 충돌이 아니다.

### 가져오기 (서버 → 옵시디언, 명시적)
- 진입점은 세 가지다.
  - 명령 "서버에서 메모 가져오기": 제목 검색 목록, 🔒 표시
  - 명령 "현재 노트를 서버 버전으로 덮어쓰기"
  - 웹의 **Send to Obsidian** 링크
- 같은 uuid의 로컬 노트가 있으면 **덮어쓰기 경고**를 띄운다. 보내지 않은 변경이 있으면 더 강하게 경고한다.
- **일괄 가져오기**(명령 "서버 메모 모두 가져오기"): 요약 확인 창을 먼저 띄운다.
  - 항목: 새 메모 N개, 🔒 암호화 메모(제목만) N개, 완료·보관 포함 여부
  - **이미 있는 노트 덮어쓰기는 기본 꺼짐**이다. 켜면 경고하고, 보내지 않은 변경이 있는 노트 수를 표시한다.
  - 가져오는 동안 자동 전송을 멈추고, 하나가 실패해도 계속 진행한 뒤 결과를 요약한다.
- **제목 보존**: 파일 이름에 쓸 수 없는 문자(`: / ? < >` 등)가 든 서버 제목은 가져올 때 frontmatter `title`에 원래대로 기록한다. 보낼 때는 `title`이 파일 이름보다 우선한다. 그래서 본문만 고쳐도 서버 제목이 바뀌지 않는다.
- 첨부는 첨부 폴더로 내려받고 `![[ ]]`로 바꾼다.
- 가져온 직후 상태는 '동기화됨'이라, 자동 전송이 되돌려 보내지 않는다.

### 상태바
✓ 동기화됨 · ● 변경됨 · ○ 아직 보내지 않음 · ⚠ 충돌 · 🔒 암호화(읽기 전용) · ✕ 오류

## 서버 API (`/api/external/sync/*`, Bearer 토큰)
| | |
|---|---|
| `GET /sync/memos` | 삭제되지 않은 모든 메모 요약 (`uuid, title, updated_at, status, is_encrypted, sync_hash`) |
| `GET /sync/memos/<uuid>` | 상세. 암호화 메모는 `content: null`, 첨부 없음 |
| `POST /sync/memos` | 생성 |
| `PUT /sync/memos/<uuid>` | 갱신. `base_hash`가 현재 서버 해시와 다르면 409, `force: true`면 덮어씀. 암호화 메모는 403 |
| `POST /sync/upload` | 첨부 업로드. 같은 내용(sha256)이 미연결이거나 같은 메모에 있으면 재사용 |

`sync_hash`는 플러그인이 관리하는 필드(title, content, 사용자 태그, group, due_date)만으로 계산한다. 기존 `/api/external/*`(MCP 서버용)는 변경하지 않았다.

## 개발
```
cd obsidian-brainsryo-plugin
npm install
npm test                    # 단위 테스트 (변환·엔진 판단 규칙)
npm run test:integration    # 실제 테스트 서버 대상 (.env 의 TEST_BRAIN_URL / TEST_EXTERNAL_API_TOKEN)
npm run build               # 타입 검사 + main.js
node scripts/install.mjs --vault "<볼트 경로>"   # 또는 OBSIDIAN_PLUGIN_DIR
```
서버 API 테스트는 `python -m pytest tests/api -q`(프로젝트 루트)로 실행한다.

**실제 Obsidian 앱 E2E**: Obsidian을 종료한 뒤 `python tests/app/run_app_e2e.py`를 실행한다(플러그인 폴더). 임시 테스트 볼트로 앱을 띄워 CDP로 22개 항목을 검증하고, 끝나면 `obsidian.json` 원복·볼트 삭제·서버 테스트 메모 정리까지 한다. 사용자 볼트는 건드리지 않는다.

구조: `src/convert.ts`(순수 변환) · `src/engine.ts`(판단, VaultPort 주입) · `src/api.ts`(전송 계층 주입) · `src/obsidian-vault.ts` · `src/main.ts` · `src/ui/modals.ts`.
엔진과 변환은 Obsidian API에 의존하지 않아 Node에서 실제 서버로 검증할 수 있다.
